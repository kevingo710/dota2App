THE APP IT SHIPPED

01 Deterministic gate

Types, lint, tests, Clean Architecture layers and a secret scan. No agent's work counts until the gate is green.

02 Evals for every agent

Each agent has its own eval cases. A change to an agent is compared against the last run before it lands.

03 Hybrid routing

Each agent runs on Claude or a local model, picked by an eval matrix, and escalates when a local fix fails.
